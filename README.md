# RodPrompt (รถพร้อม) — ระบบเช่ารถรายวัน/รายเดือนผ่านเว็บไซต์

แพลตฟอร์มรวมรถเช่าทั่วไทยแบบ Peer-to-Peer ที่เชื่อม "เจ้าของรถท้องถิ่น" กับ "ผู้เดินทางที่ต้องการรถด่วน"

## วิธีรัน
ต้องใช้ Node.js เวอร์ชัน 22.13 ขึ้นไป

```bash
npm install
npm start          # เปิด http://localhost:3000
npm run reset-db   # ล้างฐานข้อมูลกลับเป็นข้อมูลตัวอย่าง (ต้องหยุดเซิร์ฟเวอร์ก่อน)
```

## Deploy บน Render
โปรเจกต์มี `render.yaml` (Render Blueprint) พร้อมแล้ว
1. เข้า https://dashboard.render.com แล้วเลือก **New > Blueprint**
2. เชื่อมบัญชี GitHub และเลือก repo นี้ แล้วกด **Apply**
3. รอให้ build เสร็จประมาณ 2–3 นาที จะได้ลิงก์รูปแบบ `https://rodprompt-xxxx.onrender.com`
4. ดูรหัสผ่านแอดมินได้ที่ service > **Environment** > `ADMIN_PASSWORD` (Render สุ่มให้) แล้วล็อกอินด้วยชื่อผู้ใช้ `admin`

ตัวแปรที่ใช้: `NODE_ENV=production` (เปิด cookie แบบ secure), `ADMIN_PASSWORD`, `PORT` (Render ตั้งให้เอง), `DATA_DIR` และ `UPLOAD_DIR` (ไม่บังคับ ใช้ชี้ไปที่ persistent disk)

**แพ็กเกจฟรี:** ฐานข้อมูลและรูปที่อัปโหลดจะรีเซ็ตเมื่อ deploy ใหม่หรือเซิร์ฟเวอร์รีสตาร์ต แต่ระบบสร้างข้อมูลตัวอย่างกลับมาเองทุกครั้ง และเซิร์ฟเวอร์จะหลับเมื่อไม่มีคนใช้ 15 นาที ถ้าต้องการเก็บข้อมูลถาวร ให้เปลี่ยนเป็นแพ็กเกจ Starter แล้วเปิดส่วน `disk` ใน `render.yaml`

## บัญชีทดลอง
มีบัญชี 2 แบบ คือ **สมาชิก** ที่ใช้บัญชีเดียวได้ทั้งจองรถ (เมนู "การจองของฉัน") และปล่อยเช่ารถ (เมนู "ปล่อยเช่ารถ") และ **แอดมิน**

ช่องเข้าสู่ระบบพิมพ์แค่ชื่อผู้ใช้ (ส่วนหน้า @ ของอีเมล) หรืออีเมลเต็มก็ได้ **รหัสผ่านทุกบัญชีคือ `123456`**

| ชื่อผู้ใช้ | อีเมล | บัญชี |
|---|---|---|
| `host` | host@test.com | สมาชิก มีรถปล่อยเช่า 4 คัน ใบขับขี่ยืนยันแล้ว (จองรถคนอื่นได้) |
| `host2`, `host3` | host2@test.com, host3@test.com | สมาชิก มีรถปล่อยเช่า ใบขับขี่ยังไม่ยืนยัน |
| `user` | user@test.com | สมาชิก ยังไม่มีรถ ใบขับขี่ยืนยันแล้ว |
| `user2` | user2@test.com | สมาชิก ยังไม่มีรถ ใบขับขี่ยังไม่ยืนยัน |
| `admin` | admin@test.com | แอดมิน |

เงื่อนไข: จองรถได้เมื่อใบขับขี่ผ่านการตรวจแล้ว ปล่อยเช่ารถได้ทันทีไม่ต้องรอ และจองรถของตัวเองไม่ได้

## ฟีเจอร์ตามเอกสาร
- **ค้นหาและคัดกรอง**: จังหวัด วันที่ ประเภทรถ เกียร์ ที่นั่ง ราคา, "รถพร้อมใช้ด่วน", ค้นหารถใกล้ฉันในรัศมีที่เลือก
- **Instant Booking**: รถที่เปิดใช้ฟีเจอร์นี้จะยืนยันการจองทันทีหลังชำระเงิน ถ้าไม่เปิด เจ้าของรถต้องกดยืนยันเอง
- **เช่ารายวัน / รายเดือน**: รายเดือนคิดเดือนละ 30 วัน
- **ยืนยันตัวตน**: ผู้เช่าอัปโหลดใบขับขี่ แล้วแอดมินตรวจอนุมัติ ต้องผ่านการตรวจก่อนจึงจะจองได้
- **ชำระเงินผ่านระบบกลาง**: ตอนนี้อยู่ในโหมดสาธิต (PromptPay/บัตร) ระบบล็อกรถไว้ 15 นาทีระหว่างรอชำระ
- **รับรถ**: รับเองที่จุดนัด หรือให้ส่งรถถึงสถานีขนส่ง/สนามบิน (มีค่าส่ง)
- **มัดจำ**: ระบบถือเงินมัดจำไว้ เจ้าของรถคืนให้เต็มจำนวน หรือหักค่าความเสียหายพร้อมระบุเหตุผลเมื่อรับรถคืน
- **รายได้แพลตฟอร์ม**: หักค่าคอมมิชชัน (ค่าเริ่มต้น 10%) จากค่าเช่าทุกการจอง แอดมินปรับอัตราได้
- **รีวิว** หลังคืนรถ, การยกเลิกฟรีก่อนวันรับรถ (คืนเงินเต็มจำนวน)

## โครงสร้าง
```
server.js        Express API ทั้งหมด
db.js            สร้างตาราง SQLite + ข้อมูลตัวอย่าง (data/rentcar.db)
util.js          hash รหัสผ่าน, ฟังก์ชันวันที่, คำนวณระยะทาง
public/          หน้าเว็บ (index.html, app.js, style.css)
uploads/         รูปรถ และรูปใบขับขี่ (ใบขับขี่ดูได้เฉพาะเจ้าของบัญชีและแอดมิน)
seed-images/     รูปรถตัวอย่าง 12 คัน + credits.json (ระบบคัดลอกเข้า uploads/cars ให้อัตโนมัติตอนเริ่มครั้งแรก)
```

## ภาษาและหน้าตา
- สลับภาษาไทยและอังกฤษได้ที่ปุ่ม TH / EN มุมขวาบน เว็บจำภาษาที่เลือกไว้ หรือเปิดลิงก์ด้วย `?lang=en` เช่น `http://localhost:3000/?lang=en#/`
- ธีมขาวดำ ทุกสีอยู่ในตัวแปร `:root` ของ `public/style.css` (ใช้สีแดงเฉพาะข้อความ error) ถ้าต้องการสีหลักอื่น ให้แก้ `--accent`
- ตัวเลือกจังหวัด (`public/province-picker.js`) ค้นหาได้ทั้งไทยและอังกฤษ กรองตามภาค แสดงจำนวนรถในแต่ละจังหวัด และใช้คีย์บอร์ดได้
- รูปหน้าแรกและรูปภาคอยู่ใน `public/img/` พร้อม `credits.json`

## เครดิตรูปภาพ
รูปรถตัวอย่างทั้ง 12 คันมาจาก Wikimedia Commons ใช้ตามสัญญาอนุญาต CC BY-SA 4.0
ชื่อผู้ถ่ายและลิงก์ต้นฉบับอยู่ใน `seed-images/credits.json` และแสดงบนเว็บที่หน้ารถแต่ละคันและหน้า "เครดิตรูปภาพ" (`#/credits`)
ถ้านำเว็บไปใช้จริง ควรแทนรูปเหล่านี้ด้วยรูปรถจริงของเจ้าของรถแต่ละคัน
